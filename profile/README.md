# ARDA
### 하천 표류 예측 및 수색 지원 시스템

> **신고 이전 단계부터 사고를 감지하고, 표류 예측으로 우선 수색 구역을 제시합니다.**

**제22회(2026년) 창의적 종합설계 경진대회 장려상**  
인천대학교 임베디드시스템공학과 · 지도교수 최병조

## 개발 배경 및 목적

### 사고 발생 이후의 정보 공백

한강 교량의 투신 시도는 **2022년 1,000건, 2023년 1,035건, 2024년 1,272건**으로 증가했습니다. 예방 인프라와 함께, 사고가 발생했을 때 신속하게 인지하고 수색을 지원하는 대응 체계도 필요합니다.

출처: [동대문이슈 — 한강 교량 투신 시도 현황](https://www.ddmissue.com/news_view.jsp?ncd=12750)

특히 **목격자가 드문 야간에는 사고 발생 위치와 시각을 확보하기 어렵고**, 신고 이후에도 구조 인력이 도착하기까지 정보 공백이 발생합니다. 그동안 대상은 하천 흐름에 따라 이동하므로 초기 위치만으로 수색하기 어려워집니다.

### 수색 위치 판단의 어려움

국립소방연구원 조사에 따르면, **구조 대원의 79.6%가 수중 실종자 위치를 대략적인 예측에 의존**하고 있습니다. 사고 위치와 시각을 빠르게 확보하고, 이동 가능성을 반영한 수색 정보를 제공할 필요가 있습니다.

출처: [FPN 소방방재신문 — 「수중 실종자… 여기를 수색할까, 저기를 수색할까?」](https://www.fpn119.co.kr/249190)

### ARDA의 목표

**ARDA는 사고 발생부터 구조 인력의 수색이 시작되기까지의 정보 공백을 줄이는 시스템입니다.**

레이더로 낙하를 감지하고, 열화상으로 목표 대상을 추가 확인한 뒤, 확정된 좌표를 표류 예측에 연결합니다. 이를 통해 **목격자의 신고 이전 단계부터 사고 정보를 확보하고, 구조 인력이 어디부터 수색해야 할지 판단할 수 있는 우선 수색 구역**을 제공합니다.

| --- | --- |
| **곽민지(팀장)** | 프로젝트 총괄 · 시스템 통합 및 네트워크 구성 |

| **김민서** | 열화상 기반 대상 판정 |

## 시스템 동작

**낙하 감지 → 대상 확인 → 좌표 확정 → 표류 예측 → 수색 지원**

| 단계 | 처리 내용 | 결과 |
| --- | --- | --- |
| **1. 낙하 감지** | 레이더 점군에서 물체별 높이 변화 추적 | 낙하 후보 좌표·신뢰도 |
| **2. 대상 확인** | 서보 조준 후 열화상으로 열 분포·목표 형태 확인 | 대상 판정 결과 |
| **3. 좌표 확정** | 설치 위치·방향·대상 거리를 반영한 좌표 계산 | 위도·경도 |
| **4. 표류 예측** | 유속·난류·확산을 반영한 파티클 이동 계산 | 표류 예상 분포 |
| **5. 수색 지원** | 히트맵·우선 수색 좌표 제공 및 외부 장비 연동 | 수색 우선순위·이동 명령 |

## 핵심 구현

### Radar-Based Fall Detection

**TI IWR6843AOPEVM의 3차원 점군에서 물체별 높이 변화를 추적해 낙하를 판단합니다.**

- **SNR·ROI·정지점 필터링:** 잡음과 불필요한 점 제거
- **DBSCAN:** 가까운 점들을 물체 단위로 분리
- **칼만 필터·트랙 관리:** 물체별 위치와 높이 이력 추적
- **낙하 판정:** 하강 후 소실·충분한 높이 감소·자유낙하 패턴 활용
- **로지스틱 회귀:** 낙하 후보의 특징을 결합해 신뢰도 계산

레이더 내부에서 거리·속도·각도를 분석해 점군을 생성하며, 이후의 **필터링·클러스터링·추적·낙하 판정과 모듈 연동**은 팀의 프로그램이 수행합니다.

### Thermal Verification & Servo Control

**감지 방향으로 열화상 센서를 조준하고, 열 분포와 목표 형태를 추가 확인합니다.**

- MLX90640 온도 배열에서 발열 영역 추출
- 원형도·가로세로비·채움률 등 형태 특징 분석
- 온도·형태 기반 판정과 커스텀 YOLO 판정 경로 구성
- 열화상 화면의 중심 오차를 이용한 서보 방향 보정
- 설치 좌표·높이·카메라 시야를 반영한 대상 위도·경도 계산

### Drift Prediction & Search Prioritization

**라그랑지안 파티클 추적 방식을 NumPy로 구현해 여러 가능한 표류 경로를 계산합니다.**

- 유속·난류·확산을 반영한 파티클 이동
- 하천 경계를 반영한 이동 영역 처리
- 입자 분포 기반 히트맵 생성
- 우선 수색 구역과 Waypoint 선정

예측 결과는 **표류가 예상되는 분포와 수색 우선순위**로 제공해 관제 판단을 지원합니다.

### Web Monitoring & Drone Integration

**Jetson의 감지 결과를 관제 서버로 전달하고, 예측된 수색 좌표를 외부 장비의 이동 명령으로 연결합니다.**

- **HTTP:** 대상 좌표·열화상 이미지 전송
- **FastAPI·WebSocket:** 관제 상태와 예측 결과 전달
- **Web UI:** 지도·열화상·파티클·히트맵·수색 좌표 표시
- **Tello 연동:** 수색 좌표를 상대 이동 명령으로 변환해 비행 시연

Tello는 **외부 수색 자원과의 연동을 검증하기 위한 시연 기체**입니다. ARDA는 감지 결과가 좌표 확정과 표류 예측을 거쳐 수색 지원으로 이어지는 흐름을 구현했습니다.

## 기대효과

| 구분 | 기대효과 |
| --- | --- |
| **골든타임 확보** | 신고 이전 단계부터 사고를 감지해 초기 대응까지의 정보 공백을 줄입니다. 목격자가 없는 야간에도 사고 인지와 수색 준비를 지원합니다. |
| **탐색 범위 압축** | 표류 예상 분포에서 우선 수색 구역을 제시해 인력과 시간을 효율적으로 배분하고, 수색 장기화에 따른 부담을 줄이는 것을 목표로 합니다. |
| **경제성** | 교량에 부착하는 모듈 방식으로 대규모 구조 변경 부담을 줄이고, 예산에 따라 여러 교량의 필요한 지점에 분산 배치하는 구성을 지향합니다. |
| **확장성** | 한강 주요 교량을 시작으로 전국 도심의 중·소형 교량까지 적용을 확대하고, 관제 인프라가 부족한 지역의 초기 대응을 지원하는 것을 목표로 합니다. |

**팀 시연 환경에서 측정한 평균 사고 확정 시간은 10.13초입니다.** 이는 해당 실험 조건에서 측정한 결과입니다.

서울시의 2026년 수난구조대 운영 예산에는 **소방 선박 유류비 약 1억 6,200만 원**이 편성되어 있습니다. ARDA는 우선 수색 구역 제공을 통해 장기 수색에 따른 자원 소모를 줄이는 것을 목표로 합니다.
